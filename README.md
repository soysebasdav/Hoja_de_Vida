## Ejecución local

### Requisitos

- Node.js
- pnpm

### Instalación

```bash
git clone https://github.com/soysebasdav/Hoja_de_Vida.git
cd Hoja_de_Vida
pnpm install
```

### Desarrollo

```bash
pnpm dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Comandos disponibles

```bash
pnpm dev      # Inicia el entorno de desarrollo
pnpm check    # Comprueba los tipos de TypeScript
pnpm build    # Genera la versión de producción
pnpm start    # Ejecuta la versión compilada
pnpm preview  # Previsualiza el build de Vite
pnpm format   # Formatea el proyecto con Prettier
```
